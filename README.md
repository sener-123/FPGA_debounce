# FPGA 相机防抖功能（FPGA_debounce）

基于 FPGA 实现的相机防抖（Debounce / 视频防抖）功能项目。

## 项目简介

本项目使用 FPGA 对相机输入信号进行防抖处理，消除按键抖动、信号毛刺以及图像采集过程中的不稳定触发，保证相机图像数据稳定、可靠地输出。

## 功能特性

- **信号消抖**：对按键、触发等输入信号进行硬件级消抖，滤除短毛刺
- **稳定触发**：确保相机拍摄/采集触发信号的边沿干净、单次有效
- **纯硬件实现**：基于 FPGA 逻辑，延迟确定、无操作系统依赖
- **可参数化设计**：消抖时间窗口可通过参数灵活配置，适配不同应用场景

## 目录结构

```
FPGA_debounce/
├── prj/          # 工程文件（FPGA 工程配置、约束文件等）
├── rtl/          # RTL 源码（Verilog / VHDL 设计文件）
└── README.md     # 项目说明文档
```

## 开发环境

- 硬件平台：FPGA 开发板
- 开发工具：Vivado / Quartus（视具体平台而定）
- 仿真工具：ModelSim 等

## 使用说明

1. 将 `rtl/` 目录下的源码加入 FPGA 工程；
2. 根据相机输入信号频率，调整消抖计数器的参数（消抖时间窗口）；
3. 综合、布局布线后生成比特流，下载到开发板进行验证。
